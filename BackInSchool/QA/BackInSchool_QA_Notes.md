# Back in School QA Notes

현재 문서는 `지금 코드에 실제로 구현된 기능` 기준으로 작성했습니다.

포함한 범위:
- 메인 메뉴, 설정, 언어, 키 바인딩
- FlowManager 기준 일차 진행
- CHAT 지하철 구간, 건강 설문, 퇴장 게이트
- FREEROAM 이동, 대화, 포털, 플로우 상호작용
- 휴대폰 홈/앱 전환/채팅/갤러리/설정/벌점 목록
- 구현된 미니게임
  - Tetris
  - Croquis
  - Math
  - Pixel Paint
  - Presentation Typing

제외하거나 주의가 필요한 범위:
- Day 5 청소/가방정리/엔딩 계열은 Flow 상 이벤트는 있으나 실제 미니게임 구현이 완료되지 않은 부분이 있어 본 테스트케이스에서는 상세 실행 항목을 최소화했습니다.
- `도전과제` UI는 메인 메뉴 안내 문구만 구현되어 있어서 실제 업적 화면 테스트는 제외했습니다.
- 일부 테스트는 `FlowDebug` 또는 Unity Inspector를 이용한 상태 점프가 있으면 더 빠르게 검증할 수 있습니다.

권장 실행 순서:
1. 메인 메뉴 / 설정 / 실행 테스트
2. 지하철 채팅 / 건강 설문 / 퇴장 게이트
3. 자유이동 / 대화 / 포털 / 휴대폰
4. 미니게임 라우팅
5. 각 미니게임 세부 테스트

엑셀 반영 팁:
- `QA/BackInSchool_TestCases_Implemented_v0.1.tsv` 파일을 Excel에서 열면 열 구분이 유지됩니다.
- `P/F`, `실제 결과`, `비고`는 실제 테스트 수행하면서 채우면 됩니다.
