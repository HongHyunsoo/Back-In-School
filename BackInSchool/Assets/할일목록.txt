애니메이션 작업

스토브 미리 출시

맞아. 다시 제대로 정리하면, “현재 프로젝트 전체에서 사운드가 비어 있거나, 아직 지정/구현 안 된 곳”은 이 목록이야.

**1. 메인 메뉴**
- 버튼 클릭음 없음.
- 볼륨 슬라이더 조작음 없음.
- 게임 시작 시 줌/페이드 전환음 없음.
- 메인 메뉴 배경음 없음. 지하철 배경 비주얼은 있는데 메뉴용 루프 사운드는 안 붙어 있음.

**2. 공통 UI**
- 일반 버튼 hover/focus 사운드가 전체 UI에 공통 적용되어 있지 않음.
- 확인/취소/적용/뒤로 사운드 에셋은 있지만, 메인 메뉴 쪽에는 직접 연결 안 됨.
- 씬 전환 페이드 자체에는 공통 전환음 없음.
- 튜토리얼 안내 표시/갱신/목표 변경음 없음.
- 실패/성공 팝업 공통 사운드 없음.

**3. 휴대폰**
- 휴대폰 앱 버튼 클릭음은 있음.
- 휴대폰 열기/닫기 사운드 없음.
- 홈 화면 앱 진입/뒤로가기 구분 사운드 없음.
- 설정 앱의 슬라이더/키 변경 사운드 없음.
- 갤러리 사진 열기/닫기 사운드 없음.
- 사진 해금 사운드 없음.
- 규칙/급식/벌점 탭 전환 사운드 없음.
- 채팅방 입장 사운드 없음.
- 채팅 메시지 한 줄씩 뜰 때 말풍선/수신음 없음.
- 플레이어가 답장/다음 메시지를 보낼 때 전송음 없음.
- 읽음 처리/방 갱신 사운드 없음.
- 새 문자 알림음은 자유시간 컨트롤러에만 있음. 전체 휴대폰 시스템 공통 알림으로는 안 묶여 있음.

**4. 채팅/등교 지하철 장면**
- 지하철 배경 루프는 있음.
- 채팅 전용 UI 조작음은 휴대폰 버튼 클릭 외 거의 없음.
- 채팅 시작/종료 전환음 없음.
- 채팅에서 학교로 넘어가는 흐름 전환음 없음.
- 메시지 알림/수신/전송/읽음 사운드가 개별 지정되어 있지 않음.

**5. 프리롬 이동**
- 걷기 발소리는 있음.
- 달리기 전용 발소리 없음. 현재 달릴 때도 걷기 발소리를 fallback으로 씀.
- 점프 사운드 없음.
- 착지 사운드 없음.
- 계단 오르내림 사운드 없음.
- 방향 전환/급정지/벽 충돌 같은 이동 피드백 사운드 없음.
- 상호작용 가능 표시가 뜰 때 사운드 없음.
- 상호작용 실패/조건 부족 사운드 없음.

**6. 프리롬 공간/환경**
- 복도 배경음 있음.
- 운동장 배경음 있음.
- 교실 배경음 없음.
- 교실 안 학생 웅성거림/책상/의자/필기 ambience 없음.
- 보건실/미술실/컴퓨터실/계단/화장실/급식실/사물함 구역별 ambience 없음.
- 점심 자유시간 구역 전환 시 ambience fade는 있는데, 구역별 사운드가 복도/운동장 중심으로만 잡혀 있음.
- 밤/방과후 분위기 ambience 없음.
- 학교 종소리는 점심 타이머에 있음.

**7. 프리롬 문/포탈/공간 이동**
- 포탈 42개 정도가 개별 사운드 슬롯은 비어 있음.
- 다만 코드에서 문/복도 기본 전환음으로 자동 대체함.
- 즉 “기본 문소리”는 나지만, 장소별 다른 문소리/계단소리/복도 이동음은 지정 안 됨.
- 교실 문, 미술실 문, 컴퓨터실 문, 운동장 출입, 계단 이동 사운드가 전부 같은 기본 처리임.
- 엘리베이터 오브젝트는 보이지만 엘리베이터 조작/문/도착음은 없음.

**8. 사물함/오브젝트**
- 사물함에서 신발 바꾸는 적용음은 있음.
- 사물함 열기/닫기 금속음 없음.
- 서랍, 캐비닛, 책상, 의자, 문고리 같은 오브젝트 상호작용음은 대부분 없음.
- `Cabinnet.wav` 에셋은 있는데 실제 전반 오브젝트에 체계적으로 붙어 있지는 않음.

**9. 대화/스토리 공통**
- 대사 타이핑음은 있음.
- 대화 시작음 없음.
- 대화 종료음 없음.
- 선택지/다음 대사 넘김 사운드 없음.
- 캐릭터 등장/퇴장 사운드 대부분 없음.
- 표정 변화/놀람/화남/웃음 같은 리액션 사운드 없음.
- 대사별 효과음 칸은 있는데 대부분 비어 있음.
- 카메라 연출용 기본 카메라 사운드는 코드에 있음.
- 하지만 대사 CSV에서 장면별 효과음은 거의 지정 안 되어 있음.

**10. 스토리 연출**
- 방과후 D 문 닫힘/지하철 접근/지하철 지나감/열쇠음 계열은 구현되어 있음.
- 캐릭터 걷기 연출 발소리 없음.
- 문 열림 사운드 없음.
- 문 닫힘은 특정 연출에만 있음.
- 장면 전환별 분위기음 없음.
- 교실 수업 시작/끝, 조회, 종례, 방과후 전환 사운드 없음.
- 컷신 오브젝트 애니메이션에 맞춘 세부 Foley가 거의 없음.

**11. 수업/미니게임 진입**
- 수업 시작 알림음 없음.
- 미니게임 시작 카운트/준비음 없음.
- 미니게임 튜토리얼 표시음 없음.
- 미니게임 종료 후 다음 흐름 전환음 없음.

**12. 테트리스 점심 미니게임**
- 배경 루프 없음.
- 이동음 있음.
- 회전음 있음.
- 블록 고정음 있음.
- 성공음 없음.
- 실패음 없음.
- 게임오버음 에셋은 새로 들어와 있지만 현재 씬 슬롯에는 연결 안 된 상태로 보임.
- 줄/목표 달성 같은 중간 성취음 없음.
- 낙하/충돌 강조음은 없음.

**13. 크로키 미니게임**
- 배경 루프 없음.
- 연필/입력 사운드는 있음.
- 프롬프트 성공음 없음.
- 단계 완료음 없음.
- 전체 성공음 없음.
- 실패음 없음.
- 선 긋기 시작/드래그 유지/종이 넘김 같은 세부 사운드 없음.
- 선생님 말풍선 등장음 없음.

**14. 등교 연타 미니게임**
- 배경 루프 없음.
- 일반 연타음 있음.
- 마지막 페이즈 연타음 있음.
- 성공음 없음.
- 실패음 없음.
- 게이지 증가/위험 구간/완료 직전 긴장음 없음.
- 완료 후 프리롬 전환음 없음.

**15. 픽셀 페인트 미니게임**
- 배경 루프 없음.
- 칠하기 사운드 없음.
- 지우기 사운드 없음.
- 퍼즐 완성음 없음.
- 전체 성공음 없음.
- 실패음 없음.
- 색상 선택음 없음.
- 확대/축소/이동 조작음 없음.
- 오답 칠하기/정답 칠하기 구분음 없음.

**16. 영어/퀴즈 미니게임**
- 영어 듣기 음성 슬롯이 비어 있음. 설정 파일과 씬 둘 다 비어 있음.
- 단어 매칭 드래그 시작/드롭/정답/오답 사운드 없음.
- 문장 순서 맞추기 단어 선택/배치/정답/오답 사운드 없음.
- True/False 선택음 없음.
- 듣기 재생 버튼 클릭음 없음.
- 문제 전환음 없음.
- 퀴즈 전체 성공/실패 사운드 없음.

**17. 점심 자유시간**
- 타이머 종료 종소리 있음.
- 남은 시간 경고음은 종소리 하나 중심.
- 달리다 걸렸을 때 선생님 경고 사운드 없음.
- 벌점 추가 사운드 없음.
- 선생님 말풍선 등장음 없음.
- 휴대폰 알림음 있음.
- 점심 시작/종료 분위기 전환음 없음.

**18. 벌점/규칙**
- 벌점 발생 사운드 없음.
- 규칙 위반 경고 사운드 없음.
- 규칙 확인 UI 사운드 없음.
- 벌점 목록 갱신 사운드 없음.

**19. 갤러리/사진**
- 사진 촬영 사운드 에셋은 있음.
- 실제 사진 획득/해금/확인 흐름에는 전부 붙어 있지 않음.
- 갤러리 슬롯 열기/닫기/잠김/해금 사운드 없음.

**20. 우선순위로 보면**
1. 픽셀 페인트: 칠하기/지우기/완성/성공/실패 전부 비어 있음.
2. 크로키: 성공/단계완료/실패/배경 루프 비어 있음.
3. 테트리스: 성공/실패/배경 루프 비어 있음.
4. 등교 연타: 성공/실패/배경 루프 비어 있음.
5. 영어 듣기: 음성 슬롯 비어 있음.
6. 프리롬: 달리기 발소리, 교실 ambience, 점프/착지 없음.
7. 대화/스토리: 대사별 효과음 대부분 미지정.
8. 메인 메뉴: 버튼/전환/배경음 없음.
9. 휴대폰/채팅: 메시지 수신/전송/앱 전환/사진 관련음 부족.

이게 “영어 필드명 말고 실제로 어디가 비었는지” 기준의 전체 사운드 빈 곳 목록이야.
